# 교토 가족여행

2026년 11월 25–28일 일정·이동·식사·지도·예산·준비 체크리스트.

[여행 일정 열기](https://kn-data-git.github.io/kyoto-family-trip/)

모바일에서는 상단에서 날짜를 선택하고, 하단의 일정·이동·식사·지도·예산·준비 메뉴로 전환합니다.
일정과 장소를 탭하면 상세 안내가 열립니다. 이동·식사 대안은 별도 화면에 보관합니다.
예산은 가족 공통 현지 경비를 현금과 카드로 나눠 보여줍니다. 개인 쇼핑은 별도입니다.
준비 체크는 각 기기의 브라우저에 저장되며 가족 간 자동 공유되지 않습니다.
GitHub Pages는 `main` 브랜치의 루트에서 배포합니다.
`archive/`는 현재 일정과 구분한 이전 비교 기록입니다.
